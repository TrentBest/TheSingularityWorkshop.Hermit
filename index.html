A neural network you can follow

A neural network does not understand a number by magic. It transforms inputs through a sequence of explicit calculations. This tiny network has two inputs and two outputs. Change the inputs, then step through the arithmetic.

3. Follow the calculation

Inputs

The network receives x₁ = 0.600 and x₂ = 0.200.

Weighted contributions

Each input is multiplied by the weight on its connection. For example, x₁ contributes x₁ × 0.5 to neuron 1.

Weighted sums

Contributions arriving at each neuron are added.

z₁ = 0.220
z₂ = −0.020
Bias

A bias shifts the weighted sum before activation.

z₁ + b₁ = 0.320 (b₁ = 0.100)
z₂ + b₂ = −0.220 (b₂ = −0.200)
Activation

The sigmoid function maps each biased sum to a value between 0 and 1: σ(z) = 1 / (1 + e−z).

Outputs

The final values are the network's prediction for these inputs. The weights and biases stayed fixed throughout.

The actual equations

y₁ = σ((0.600 × 0.5) + (0.200 × −0.4) + 0.1)
y₂ = σ((0.600 × −0.3) + (0.200 × 0.8) − 0.2)

4. What did we just do?

A neuron receives values, multiplies each by a learned or chosen weight, adds the contributions, adds a bias, and applies an activation function. A layer is a collection of neurons performing this process.

Inference is using the current weights and biases to calculate an output. This lesson performs inference only. Learning is a separate process that changes weights and biases based on examples and an optimization rule. Nothing in this demonstration trains the network.

The weights are deliberately fixed so you can isolate the computation. Later lessons can introduce hidden layers, different activation functions, training examples, loss, gradients, and optimization one concept at a time.

This is an educational, deterministic demonstration. It does not connect to a live AI model, use a GPU, or take actions in an environment.
